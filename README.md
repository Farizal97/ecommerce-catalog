# ecommerce-catalog

Final Task CI - Front End.

## Teknologi
- Vue.js 2.7
- Vanilla CSS
- JavaScript Fetch API
- Fake Store API
- Git & GitHub

## Menjalankan
npm install
npm run serve

## Build
npm run build

## API
https://fakestoreapi.com/products/{index}

Index berjalan 1-20. Jika lebih dari 20, kembali ke 1.

## Kategori
- men's clothing -> Page Men section
- women's clothing -> Page Women section
- kategori lainnya -> Page Unavailable product
